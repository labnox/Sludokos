📱 App Installeren (PWA)

Je kunt Remix Sludoko installeren als een Progressive Web App op je telefoon of desktop zonder app store:

  • Chrome / Edge / Android: Klik op de 3 puntjes rechtsboven in de browser en kies "App installeren" of "Toevoegen aan startscherm".
  • Safari op iPhone/iPad: Tik op de Deel-knop (vierkantje met pijl omhoog) en kies "Zet op beginscherm".
